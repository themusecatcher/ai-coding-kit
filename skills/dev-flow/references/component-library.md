# 组件库使用规范

## 1. 必须先查阅组件文档

- ✅ 先通过 MCP 工具或文档查阅组件 API 和属性
- ✅ 优先使用组件原生属性而非 CSS 覆盖
- ❌ 禁止不查文档直接凭经验写代码

## 2. 使用组件 API 前必须阅读源码确认实际行为

- ✅ 覆盖默认样式时先确认是 CSS 还是 JS 内联样式
- ✅ 使用 `style`/`maskStyle`/`overlayStyle` 等属性时确认源码中的合并顺序
- ✅ 行为与预期不符时从源码追查根因
- ❌ 禁止假设组件 API 行为——实际实现中可能被覆盖或忽略

## 3. 文档查不到时先问用户

- ❌ 禁止自己猜测或直接用 CSS 覆盖

## 4. 样式引入不能遗漏

- 如需单独引入样式则必须正确引入（如你的组件库的样式文件）
- ❌ 禁止修改文件时意外删除样式引入语句

## 5. JSX 语法规范

- 布尔值属性必须使用花括号：`bordered={false}` 不能写 `bordered="false"`
- 含 JSX 的文件必须使用 `.tsx` 扩展名
